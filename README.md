# IcoGenerator



A command line utility to covert png images into ico files.



## Usage



IcoGenerator <input.png> <output.ico> \[sizes]



Example:

IcoGenerator my\_picture.png my\_ico.png 16,20,24,32,40,48,64,128,256



*Note if you skip argument 3, the following szies will be used:

16,20,24,32,40,48,64,128,256\*
